# 体験の流れ

人がどの順に何を見るか。画面を動かす判断は、この流れのどこかに必ず対応する。

## 準備（1回だけ）

1. 導入して、キーを送る小さなアプリにアクセシビリティ許可を出す
2. ターミナルのすぐ後ろのウィンドウで動画を開き、**止めたまま**にしておく

## ふだんの1周

1. エージェントに仕事を投げる
2. 手を止める（3秒）
3. **予告が出る**（まもなくブラウザへ移る、と知らせる）
4. ブラウザが前に出て、動画が動き出す
5. エージェントが質問したか、終わった
6. 動画が止まり、ターミナルが前に出て、**呼んだペインまで移る**
7. 読む。読んでいるあいだは、サイドバーのその行に `to be read` が出る
8. 次を投げる → 1へ

## 途中でやめるとき

- 予告が出ているあいだに手を動かすと、**中止**になる。中止も知らせる
- 帰り先（ターミナルなど）以外のウィンドウで作業していたら、連れ出さない
- `recess off` にすると、状態は追うが画面は動かさない
