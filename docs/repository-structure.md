# 責務分担

どのファイルが何を持つか。似た処理を増やす前にここを見る。

| 置き場 | 持つもの | 持たないもの |
| --- | --- | --- |
| `recess-watch.py` | 状態の収集・判定・画面を動かす指示 | 導入手順、権限の設定 |
| `recess-mode.sh` | ON / OFF / 状態表示 | 判定 |
| `hooks/` | AIが自分の状態を書き残す仕掛け | 判定 |
| `install.sh` | 置く・作る・登録する | 判定 |
| `uninstall.sh` | `install.sh` が置いたものを外す | — |
| `herdr-plugin.toml` | herdr から呼べる操作の宣言 | 実装 |
| `docs/` | 仕事・体験・設計・仕様・導入説明 | 実装 |
| `tools/` | 調べもの用の使い捨てスクリプト | 本番の経路 |

## 決めごと

- **判定は `recess-watch.py` の1か所に置く。** 同じ判断を hook 側や CLI 側に書かない
- **hook は状態を書くだけ。** 連れ出すかどうかを hook で決めない
- `tools/` のスクリプトは常駐から呼ばない
- 状態と記録はすべて `~/.local/state/recess/` の下。repo には置かない
- 同じ判定を2か所に書きたくなったら、判定を関数へ出して1か所から呼ぶ
