# 枠組みの決めごと

使う道具と、守る約束。

## 言語と依存

- 常駐は **python3 の標準ライブラリだけ**。パッケージを入れない（導入のハードルを上げない）
- CLI と導入は **sh**。bash 専用の書き方をしない
- キーを送るアプリは **AppleScript 1行**

## 他人のプロセスを止めない

- hook は**失敗しても必ず正常終了する**。AIの動作を1秒も止めない
- 常駐は1周で例外が出ても落ちない。記録を残して次の周へ進む
- 常駐が落ちたら launchd が戻す（異常終了のときだけ）

## 外へ出すもの

- 秘密をファイルに持たない。ssh の鍵は各自のものを使う
- 記録に出すのは状態と判断の理由だけ。プロンプトの中身を書かない

## 確かめ方

- 画面を動かす判定は、**実コードを読み込んで最前面アプリだけ差し替えるハーネス**で確かめる（画面を動かさずに分岐を見る）
- 構文は `python3 -m py_compile`
- 事後の確認は `watch.log` の集計（何回動いて、そのとき前面が何だったか）
- 画面が動くふるまいは、机の上で1日動かしてから「できた」と言う
