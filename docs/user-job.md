# 誰のどの仕事か

Recess が片づける仕事を1か所に書く。機能を足すか迷ったら、ここへ戻る。

## 使う人

AIエージェントに仕事を投げて、返事を待つ人。複数のエージェントを同時に動かしていることが多い。

## 片づけたい仕事

**AIが働いている数十秒から数分を、安心して離れられる時間にしたい。**

待っている間に別の作業を始めると、呼ばれたときに頭の中が二重になる。かといって画面を見つめて待つのは退屈で、しかも疲れる。「AIを使っているのに、なぜか頭が疲れ切る」——Brain Fry と呼ばれる状態が動機。

## 満たすべきこと

- 離れていても、呼ばれたら確実に気づける
- 戻ったとき、どのエージェントが呼んだのかを探さなくてよい
- 休憩に行くかどうかを、人が毎回判断しなくてよい

## この道具がやらないこと

- AIが何の仕事をしているかを理解すること（状態しか読まない）
- 動画の再生状態を管理すること（スペースを1回送るだけ）
- 休憩を強制すること（ON / OFF は人が決める）
