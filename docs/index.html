Spacr

AI が働いている間は Netflix。呼ばれたら止めて、ターミナルへ戻る。

Spacr は、AI エージェントが作業を進めている間は Safari で Netflix を再生し、AI から質問か完了の知らせが来たら再生を止めてターミナルを前に出す、Mac 用の小さな常駐です。herdr で AI エージェントを回している人向けです。

AI は道具だ。任せる範囲、呼ばれる時機、戻り方の3本の線を自分で引いたら、AI が夜の作業を進めている横で、Netflix をまったく見なかった私が Netflix を楽しんでいた。道具として使って楽しみが増えた。

私は AI を批判していない。積極的に使っている。それでも毎日、脳の疲れを感じる。AI を多数立てて回すのは、私はしたくない。このページは、その私が引いた線と、動いている実物の置き場です。コードは AI に書かせ、目的・権限・止め方は私が決めた。

3本の線

線1 任せる範囲

私が見ていない間も動く常駐に、鍵は渡さない。キー1回分の1行アプリ（Spacr.app）にだけ、アクセシビリティの許可と、System Events を制御するオートメーションの許可を出した。python3 には出していない。「python3 に許可を与えるのはちょっと怖い」が理由で、Safari の設定も変えていない。ただし、herdr に登録した他のマシンの状態は、常駐が手元の ssh 鍵で読みに行く。いっぽうで AI 本体には、作業中はシェルを丸ごと渡している。

線2 呼ばれる時機

連れ出す側は慎重に、呼び戻す側は即時。Netflix へ連れ出すのは、見ているタブ（フォーカスしているペインと、同じタブに並ぶペイン）の AI が働いている（working）ときだけ。それも、どこにも質問と未読の完了が無く、そのタブに読み中のペインが無く、手を離して3秒たち、最前面がターミナルで、最後に呼び戻されてから20秒以上たっているとき。AI が止まっている（idle）ときは行かない。次を打つ準備の時間だから。以前の版は AI が止まっていても連れ出していて、呼び戻された直後に2〜3回 Netflix へ戻される原因になっていたので、そこは閉じた。ターミナルへ呼び戻すのは、どこかに新しく現れた質問と完了、それと、見ているタブの AI が working から idle になったとき。起動したときに既にあるものでは呼ばない。人の邪魔になりうる側だけ慎重にした。

線3 戻り方

スペース1回、0.3秒、ターミナル。呼ばれると Spacr.app がスペースを1回送って再生を止め、0.3秒待ってターミナルを前に出す。切り替わったことは私の目で見た。呼び戻しは約8分に1回の細切れだったが、見なかった私が見た。

入れる

1行目で install.sh を手元に落とす。中身を読む。2行目で実行する。install.sh は実行時に常駐本体 spacr-watch.py も同じ場所から取得するので、読んでから入れたい人は両方を読む（GitHub に同じものがある）。

curl -fsSLO https://raw.githubusercontent.com/tatsuro-ueda/spacr/main/install.sh
sh install.sh

spacr.feel-physics.jp が応答しないときは、同じファイルを GitHub から: curl -fsSLO https://raw.githubusercontent.com/tatsuro-ueda/spacr/main/install.sh

対象は macOS 14 以降と herdr 0.9.1 以降。私が確かめたのは macOS 14.3.1、herdr 0.9.1、Safari の Netflix です。

入れると何が起きるか

  1. 常駐が立つ。launchd の LaunchAgent として ~/.local/share/spacr/spacr-watch.py（Python 3 の標準ライブラリだけ）が登録され、ログインのたびに起動する。2秒おきに herdr agent list を読み、状態の変化を見て、ブラウザかターミナルを open -a で前に出す。herdr に登録した他のマシンがあれば、そのマシンの状態も ssh で同じように読みに行く。
  2. Spacr.app が作られる。中身は AppleScript 1行 tell application "System Events" to key code 49（スペースを1回送る）。手元で osacompile により作られ、~/Applications に置かれる。ビルド済みのものは落とさない。壊れていない Spacr.app が既にあれば作り直さない（作り直すのは sh install.sh --rebuild-app のとき）。
  3. 許可を2つ求める。1つは アクセシビリティ。「システム設定」の「プライバシーとセキュリティ」にある「アクセシビリティ」で、Spacr.app を手で追加してオンにする。もう1つは オートメーション。初めてスペースが送られるとき「Spacr が System Events を制御しようとしています」と聞かれるので「許可」を選ぶ。どちらも相手はこの1行アプリだけ。
  4. python3 には権限を出さない。常駐はキーを送らない。ブラウザとターミナルを前に出すだけで、それには権限が要らない。Safari の設定も変えない。

分かっている弱点

  • スペースは再生と停止の切り替えで、「再生しろ」「止まれ」という命令ではない。手で再生状態を変えると往復が逆になる。ターミナルにいる間は Netflix を止めておく、と私が運用で合わせている。
  • 確かめたのは私の Mac の Safari と Netflix だけ。別のブラウザ、別のタブ、別のユーザーアカウント、OS 更新後は確かめていない。
  • Safari を前に出すだけなので、Netflix の正しいタブや動画へのフォーカスまでは保証しない。最初に一度、動画をクリックしてフォーカスを置く必要がある。
  • 見ているタブの AI が working なら、手を離して考えごとをしている最中でも Netflix へ連れて行かれる。この穴はまだ直していない。
  • ターミナルでもブラウザでもないアプリ（Finder やエディタ）を見ているときに呼び戻されると、それでもブラウザを前に出してスペースを押す。
  • Spacr.app を作り直す（sh install.sh --rebuild-app。壊れているか古い版のときは再実行でも作り直す）と、出した許可が外れることがある。外れたら、一覧から削除して追加し直す。それ以外のただの再実行では作り直さない。
  • 再生が始まったかどうかを常駐は読めない。ログに残るのは「送った」記録だけで、切り替わりは目で確かめた。
  • 応答しなくなった他のマシンは、最後に分かった状態を持ち続ける。いなくなった扱いにはしない。
  • 手を離した秒数はこの Mac の入力装置から取る。スマホから ssh で打っていても「手」には数えない。
  • ssh が遅いと、他のマシンからの呼び出しは次の herdr agent list が返るまで遅れる。
  • herdr が無いと何もしない。Mac 以外では動かない。
  • 測っていないこともある。生産性は測っていない。疲れが減ったかも測っていない。言えるのは、最初の一晩は線を引くのに消えて、線は翌日も残っていた、まで。

様子を見る

常駐の判断は ~/.local/state/spacr/watch.log に残る。plist の EnvironmentVariables に SPACR_DRY_RUN=1 を書いて載せ直すと、判断はログに書くが何も押さず何も切り替えない。私は最初の1日をこれでログだけ読むのを勧める。launchd から起動できないときは同じフォルダの watch.stderr.log を見る。

止める、動かす、消す

止める（常駐だけを降ろす。次にログインするまで止まったまま）:

launchctl bootout gui/$(id -u)/jp.feel-physics.spacr

動かす:

launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/jp.feel-physics.spacr.plist

消す（install.sh が置いたものを全部外す。同じリポジトリの uninstall.sh を落として実行する。ログも消すなら --purge）:

curl -fsSLO https://raw.githubusercontent.com/tatsuro-ueda/spacr/main/uninstall.sh
sh uninstall.sh

手で消すなら、置いたものはこれで全部:

launchctl bootout gui/$(id -u)/jp.feel-physics.spacr
rm ~/Library/LaunchAgents/jp.feel-physics.spacr.plist
rm -r ~/Applications/Spacr.app ~/.local/share/spacr ~/.local/state/spacr
rm ~/.local/bin/afplay   # --with-afplay で入れたときだけ

アクセシビリティとオートメーションの一覧に残る Spacr の項目は、システム設定から手で外す。
